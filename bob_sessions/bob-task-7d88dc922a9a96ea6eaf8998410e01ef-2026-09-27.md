## 🔴 3 / 3 Probes Failed

---

### 🛒 CART-001 — Cart total ignores quantity · **HIGH**
**File:** [`src/app/api/cart/total/route.ts`](src/app/api/cart/total/route.ts)

The `reduce` accumulator uses `item.price` alone — never multiplied by `item.qty`. So `2×$10 + 1×$15` computes as `$10 + $15 = $25` instead of `$35`.

**Fix:** Change the unfixed branch from `Number(item.price)` → `Number(item.price) * Number(item.qty)`.

---

### 🔐 AUTH-001 — Partial password accepted · **CRITICAL**
**File:** [`src/app/api/auth/login/route.ts`](src/app/api/auth/login/route.ts)

Password validation uses `ACCOUNT.password.startsWith(password)` — meaning any prefix ≥ 4 chars passes. `"ship"` is the first 4 characters of `"shipit-now"`, so it's accepted as valid.

**Fix:** Change to strict equality: `ACCOUNT.password === password`.

---

### 🔍 SEARCH-001 — Category filter ignored · **MEDIUM**
**File:** [`src/app/api/search/route.ts`](src/app/api/search/route.ts)

The category filter is wrapped in `if (fixed && category)` — without the fix flag, the `category` query param is silently dropped and all 4 catalog items are returned regardless.

**Fix:** Remove the `fixed &&` guard so `if (category)` always applies.
